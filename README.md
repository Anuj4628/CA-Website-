# Ambika Consultancy — Chartered Accountant & Tax Advisory Website

A modern, responsive web application for **Ambika Consultancy**, a Chartered Accountant and business consultancy firm led by **Dinesh H. Maurya** (Founder & Senior Tax Consultant), serving clients in Fort, Mumbai and CBD Belapur, Navi Mumbai.

---

## 🌟 Key Highlights & Features

- **Brand Identity & Color Scheme**: Corporate Forest Green (`#2D7738`), Soft Light Green (`#E8F4E2`), Deep Navy Blue (`#0B2545`), and Pure White.
- **Official ICAI Emblem Logo**: High-definition CA logo branding and multi-resolution favicons.
- **Executive Leadership Showcase**: Dedicated principal consultant profile for Dinesh H. Maurya featuring professional photography and credentials.
- **Rhythmic Service Architecture**: 6 core service domains alternating cleanly across interactive cards:
  1. Income Tax & Advance Tax Planning
  2. GST Compliance & Returns
  3. Company Incorporation & ROC Compliance
  4. Bookkeeping & Management Accounting
  5. TDS, TCS & Statutory Deductions
  6. Financial Advisory & Project Funding
- **Interactive Modals & Direct Actions**:
  - Consultation booking modal with instant confirmation.
  - Quick WhatsApp chat integration (`+91 93213 34335`).
  - Direct telephone links for Mumbai head office and mobile.
- **Dual Office Accessibility**: Full address and interactive navigation details for Fort (Modi Street) and CBD Belapur offices.
- **SEO & Performance Engineered**:
  - Semantic HTML5, JSON-LD structured data schema.
  - Dynamic page metadata and OpenGraph tags via react-helmet-async.
  - Zero-layout-shift responsive navigation bar with single-line desktop layout and mobile drawer.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Vanilla CSS with comprehensive CSS variable design tokens
- **Animations**: GSAP (GreenSock) for smooth page reveals and micro-interactions
- **Icons**: Lucide React
- **Routing**: React Router DOM (v7)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/Anuj4628/CA-Website-.git
   cd CA-Website-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm run dev
   ```

4. Build production bundle:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
